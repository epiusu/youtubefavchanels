# 📺 Harika Kanallar & Kaynaklar

Bu proje, [şu Google Dokümanı’nda](https://docs.google.com/document/d/1M5kvDldTCDCNgrlNx6fcDF1h81fnKX6Ovvm20L06Jtk/edit) toplanmış olan **500’den fazla YouTube kanalını** ve **podcast, web sitesi, eklenti, yazılım** gibi diğer kaynakları tek bir modern web arayüzünde sunar.

## 🚀 Özellikler

- **Koyu tema** – göz yormayan, okuması rahat bir tasarım.
- **Anlık arama** – kanal adı veya açıklamaya göre filtreleme.
- **Kategori filtreleri** – istediğiniz konuya tek tıkla odaklanın.
- **Tamamen duyarlı (responsive)** – mobil, tablet ve masaüstünde kusursuz görünür.
- **Tek dosya** – tüm stiller ve mantık `index.html` içinde, kurulum gerektirmez.
